# AutoWallet

Virtual card + person-to-person send. Frontend first.

**Stack:** Next.js (App Router) · TypeScript · React · Tailwind

Send updates mock balances in the browser. A Postgres ledger (`packages/ledger`) is next — keep money logic out of route files when it lands.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If Publix is already on 3000, Next will pick 3001.
